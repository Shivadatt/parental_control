**line-cited read of the current tree**, or a **read-only hosted observation** — labelled per row. Severity bands are
unchanged (P1 wrong data / live exposure · P2 honest-but-misleading or unproven claim · P3 hygiene).

Nothing in this file was fixed by silently expanding scope, and nothing here is claimed as deployed.

## 3. Rules that prevented a fix

* **Do not silently choose product behaviour** → PRIV-01 untouched, SQL-05 atomic RPC kept as a proposal.
* **Do not expand scope without a documented reason** → SQL-04 Option B rejected with evidence (it would make
  `rpc('run_retention_sweep')` ambiguous, PGRST202); PERF-01 shape swap skipped for unproven batch equivalence.
* **No new client-callable RPC / contract-breaking change** → the proposal is service-role-only and unapplied.
* **Do not deploy or mutate hosted systems** → HOST-01/HOST-02 are reported, not repaired.
* **Do not claim JVM tests passed while Gradle is blocked** → KOT-01 says `NOT EXECUTED`, twice.
